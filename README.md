# ShaadiChitthi — Luxury Digital Wedding Atelier
> **“Shaadi ka digital nimantran, dil se.”**

ShaadiChitthi is an interactive digital wedding invitation platform crafted for modern Indian celebrations. Built with bespoke 3D invitation reveals, relaxing piano sound effects, real-time customization atelier, live wedding countdown timers, ceremony itineraries, and seamless WhatsApp sharing.

## ✨ Features
- **Cinematic 3D Hero Invitation:** Textured ivory envelope, burgundy inner velvet lining, handcrafted wax seal, and elegant card reveal.
- **Interactive Invitation Showcase:** 6 distinct themes (Royal Rajasthani, Modern Minimal, Floral Romance, Traditional Indian, Contemporary Luxury, Festive Celebration).
- **Interactive Wedding Website Demo:** Full microsite demo for Aarav & Meera with countdown, itinerary, Google Maps venue integration, photo gallery, and RSVP with celebration feedback.
- **Real-Time Customization Studio:** Live bride & groom personalization, color accent picker, live ticking countdown, and direct WhatsApp order generator (+91 91574 17895).
- **Relaxing Acoustic Piano Engine:** 100% offline Web Audio API acoustic piano progression that plays smoothly by default.
- **Mobile-First UX:** Sticky mobile quick bar, thumb-friendly navigation, and responsive touch controls.

## 🚀 Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build
```
